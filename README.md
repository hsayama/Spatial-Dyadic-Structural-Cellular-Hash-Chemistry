# Spatial Dyadic Structural Cellular Hash Chemistry

This repository contains several Mathematica codes related to the following manuscript:

* Ilya Horiguchi and Hiroki Sayama, Hash Chemistry: Minimal models for evolutionary growth of complexity. arXiv preprint https://arxiv.org/abs/2607.28219 .

Details of the files are as follows:

* spatial-dyadic-SCHC-interactive-demo-rev.nb (debugged on 10/3/2026)

  * Mathematica code for running an interactive visual simulation of Spatial Dyadic Structural Cellular Hash Chemistry (SD-SCHC).

* spatial-dyadic-SCHC-systematic-sim-rev.nb (debugged on 10/3/2026)

  * Mathematica code for running systematic simulations of SD-SCHC and generating log files.

* spatial-dyadic-SCHC-systematic-sim-data-analysis.nb

  * Mathematica code for reading the simulation log files and generating aggregated data files.

* spatial-dyadic-SCHC-systematic-sim-data-analysis-plotting.nb

  * Mathematica code for plotting the results on the aggregated data files. This notebook file already contains some of the visualization results.

Some aminations of the simulation results are also available on https://www.youtube.com/@ComplexSystem/shorts .
